Лаба 2 — Мониторинг сервиса: метрики, логи, трейсы

Будучи презренным пользователем Windows, было принято решение выполнять лабы на виртуальной машине Ubuntu Server 24.04

С настройкой ВМ и установкой Docker/kind/helm особых проблем не было, а вот с kubectl пришлось повозиться.
Официальный apt-репозиторий оказался недоступен, точнее, доступен, но на скорости 111 байт/сек и с таймаутами на скачивании пакета.
Пробовал зеркала Rancher, Azure China, storage.googleapis.com, везде 404. В итоге использовал Docker, выкачал образ gcr.io/cloud-builders/kubectl,
через docker cp вытащил из него kubectl и положил в /usr/local/bin.

# Часть 0 - сервис api

С помощью ИИ сгенерил небольшой сервис на Python FastAPI с четырьмя эндпоинтами:
- GET /health - возвращает ok
- GET /fail - возвращает 500 и увеличивает счётчик ошибок
- GET /slow - спит 1–3 секунды
- GET /load - дёргает сам себя пачкой запросов, чтобы подскочил RPS
